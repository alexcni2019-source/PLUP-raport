# NRG PLUP · Corporate workspace

Implemented from the separately approved interactive design proposal, November 2026.

## Scope

- NRG sidebar on desktop and fixed bottom navigation on narrow screens; existing theme/system controls and private login remain available.
- Home prioritizes the latest production draft, real saved-report totals with an explicit period, recent reports, and drafts. Detailed trend analysis is a disclosure.
- Production uses AL/CU field groups, one editing day at a time for weekend reports, canonical total/waste summaries, and existing report diagrams.
- Plan and forecast use one set of existing controller fields, presented as desktop tables or mobile product cards. Secondary stock/measurement/notes fields open via Detalii. Search covers the visible primary field values and filters by material.
- Source-table mode retains its exact imported columns, headers, records and editor. Numeric validation preserves rejected text on screen and blocks navigation, saving and export until correction.
- Save states distinguish drafts, pending edits, loaded history records, and successful server saves. Errors retain inputs. Existing import-review gates, backend rendering and history IDs are preserved.

`web/corporate.css` is the approved presentation layer loaded after the existing module styles. `web/corporate.js` supplies responsive row markup and presentation derived from the existing controllers; it does not replace persistence or authentication. Existing controllers emit small presentation events for navigation, drafts and saved state.

Bootstrap 5.3.8 is installed via npm and locked in package-lock.json at the user's request. It is available for further component work; global Bootstrap CSS/JS is not loaded into the application. Python remains the runtime; npm is not required to start the server.

## Verification

- All 78 existing Python tests passed.
- Chromium against a separate local SQLite database: daily totals and waste denominator, inline errors, failed-save retention, successful saves, history updates with stable IDs, three-day editing, real PNG generation, plan/forecast filtering, optional forecast status, import-review confirmation, exact imported source cells and extra columns.
- All six navigation/report modes fit 320, 390, 768, 1024 and 1440 CSS-pixel widths in light and dark themes; reduced motion disables transitions. No JavaScript errors in those flows.
- PNGs are generated by the existing Python renderers; no renderer or production-data migration is included in this UI change.
- Browser emulation is not a physical iOS/Android test. OCR review uses an explicitly restored extracted draft; it does not measure recognition accuracy.
