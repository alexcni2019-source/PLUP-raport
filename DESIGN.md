# PLUP approved visual system

Task-oriented web application (Operate). One final combined appearance, no proposal picker.
Teal identity and compact navigation, warm cream surfaces and Source Sans 3 typography,
Emerald's explicit separation of AL/CU editing. Source Sans 3 is self-hosted with its OFL.

Light: cream #fffdf1, paper #fffef9, teal #006b65, ink #1e342e.
Dark: warm green #141f1a, paper #1e2c24, mint action #64dbc4, ink #fff9e9.
AL uses blue and CU copper, consistently labeled; state never relies on color alone.
Use readable 16–18px form/body text, tabular numbers, fixed heading scales, generous
field spacing and responsive structural changes. Keep visible keyboard focus.

Apply original PLUP adaptations of public Untitled UI examples through the installed
shadcn/Radix components: grouped header actions, clear material headers, unit adornments,
featured metric icons, segmented filters and understated depth. Mouse effects require
a fine pointer; reduced motion removes movement. Avoid decorative page-load choreography.

Preserve controllers and API contracts while composing the working views into React.
No embedded prototype data or mocked saves in production. Import, history, drafts and
exports remain connected to the existing Python service. Render real report data using
the matching palette/font; never generate report figures with AI imagery.
