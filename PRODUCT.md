# PLUP

Private Romanian production reporting application for NRG Cables' PLUP department.
The authorized user imports, verifies, edits and saves production, three-day, plan and
forecast reports and generates PNG exports. Python owns validation, calculations,
identity authorization, SQLite reports/drafts/history, import and rendering.

Keep exact dates and report identity, decimal precision, blank detail-cell policy,
separate AL/CU products, clients and stages, and optional forecast status visibility.
Retain existing import review, stock, undo, source-table and history workflows.
Never replace real data with demonstration content. Production access remains private.

The user approved integration of the reviewed React prototype and its combined
Teal Signal / Cream & Citrus / Emerald Focus visual system, including Application UI
finishes and restrained interaction.
